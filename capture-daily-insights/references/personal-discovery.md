# 个人探索

入口：[Skill](../SKILL.md)。

个人探索不是测试，没有标准答案。不强迫披露隐私，不假定所有人经历过大学、就业、婚育；不适用阶段可跳过或改成用户实际阶段。

## 两种入口

用户要做基础信息梳理时，提供“领取空白模板自行填写”和“通过对话逐题梳理”两个选项，已有明确选择则直接开始。用户只想围绕已有记录深入讨论时，直接使用下方定向追问，不要求先填问卷。
使用模板收集时，完整阅读所选模板：[热爱擅长价值观](../assets/self-discovery.md)、[人生关键事件](../assets/life-events.md)。两者可并行，不设完成门槛。

### 填写模板

发送初始化后两份实际文件的链接（宿主支持附件则附文件），不只报出文件名。用户可离线填写、跳题、分次上传。
收到回答时保存原始文件或完整文字，标记来源和收到日期；不覆盖空白模板。分次版本保留历史，新增回答与已有回答冲突时请用户澄清，不静默选择。
用户未提供情绪时不补造。只根据已答内容整理，空白保持未知。

### 多轮访谈

每轮一个问题或少量紧密相关的问题，优先用户想聊的部分。问题使用模板中的章节名+序号作为稳定标识。
已经从用户材料得知的信息先总结确认，不机械重复发问。追问具体经历、当时判断和结果，不诱导、审问或诊断。
保存到探索目录：访谈记录.md（逐轮问题、完整原话、日期）、访谈进度.md（已答／部分回答／跳过／待答、来源锚点、下一题）。更新目录索引。跳过不算缺陷，随时暂停后可继续。
可跨对话恢复的前提是宿主能够读取这些文件；不能承诺没有存储支持也能永久记住。

## 访谈选题、回应与收束

以下规则同时适用于模板访谈和定向追问；一组访谈指围绕同一主题的连续交流，不等于每条消息。

- **选题理由**：每组开始或转向新主题时，用一句话说明想弄清什么、为何值得问。优先选择能补足关键条件、区分不同解释或帮助当前现实选择的问题；基础信息缺口也可直接说明，不为选题制造假设。不以填满问卷或增加已答题数为目标，同组追问不重复解释目的。用户要求一次只问一个问题时遵循该节奏。
- **低打扰回应**：根据新增信息简短承接，只在有必要时澄清或追问；不把每句回答都提炼为能力、优点、缺点或人格判断，不反复复述与评价。重要更正及时说明，阶段发现集中到收束时表达。减少对话中的分析篇幅不减少已授权原话、来源和进度的保存；用户要求只讨论不记录时仍不保存。
- **每组收束**：已有材料足以回答本组探索问题时及时结束，不等待所有细节齐全。用户记不起来、信息开始重复，或剩余缺口暂不影响当前判断时，可以保留未知并收束；暂停与跳过立即尊重。简短说明本组了解到什么、仍不确定什么，并在进度中标记已答／部分回答／跳过及收束状态。收束不代表假设已证实、画像已更新或全部访谈已完成；不为结束强行下结论，也不在同一回复自动接上新主题，除非用户已要求继续。

上述规则只调整访谈节奏；原话保真、来源归属、证据核对、隐私、用户控制及画像版本规则继续适用。

## 基于记录的定向追问（可选）

触发：“针对这条继续问我”“帮我深入了解自己”，或用户接受了深入探索的邀请。普通“记一下”先完成记录；确有重要缺口时可简短邀请，不默认开始提问。用户说只记录、先讨论不记录、暂不探索或批量未发完时遵循其限制，不反复邀请。

1. 从相关索引、原话、已答问卷或画像的待验证区找到一个值得核对的问题。先读已有答案及真正相关的来源，不重问已知信息，不扫描无关材料。
2. 用一句话说明这轮想弄清什么，区分用户原话与 Agent 暂定解释；没有明确假设时也可只澄清信息缺口，不为提问制造心理动机。
3. 一次聚焦一个关键问题，优先具体经历、当时可选方案、选择依据和实际结果；寻找反例或不同条件下的选择，而非只搜集赞同答案。提问不预设用户应当认同的解释。
4. 延续原访谈文件：在“访谈记录.md”保存问题、完整回答、日期与来源；在“访谈进度.md”维护探索问题、依据、已答／待答／跳过和下一步。定向问题使用独立的 `X001` 等稳定标识，不冒充模板题号；只讨论不记录时不写文件。
5. 只按新信息澄清、补问或修正假设；跳过或暂停即停止，不要求每天回答。探索阶段的问题与暂定解释留在访谈进度，只有用户要求整理画像时才按[画像流程](profile-curation.md)重新核对并更新画像，不直接提升为稳定结论。

涉及真实选择时，按需问清当时的角色与决策权、时间／预算／关系约束、可选方案与可逆性。只追问影响判断的条件；未知保持未知，不把每条记录都扩展成问卷。

### 按需选用的提问视角

- 成本与机会成本：投入这件事时放弃了什么？
- 权责与激励：谁能决定、谁承担后果、谁获得收益？
- 价值冲突：两个都重视的东西冲突时如何取舍？
- 风险与可逆性：最坏结果是什么，能否回退？

每次选最相关的一两个视角即可，不轮流套用学科。思想实验和假设场景只能生成探索线索，回答标为“假设回答”，不是行为验证；比喻用于说明，不当作心理机制证据；数学结论须有数据与假设支持。不诊断潜意识、天赋或固定人格，不要求得出一个解释一生的统一答案。

## 整理画像

用户明确说“整理画像”“更新画像”或提出等价要求时，完整读取并执行 [画像整理标准](profile-curation.md)。收到已填写模板本身时先保存原始回答，不默认认为用户同时要求生成画像；可告知用户下一步说“整理画像”即可。

个人探索、记录和画像整理相互独立。问卷未全部填完或记录不足半年也能整理，但必须标记缺口；用户可以只记录而完全不做画像。
